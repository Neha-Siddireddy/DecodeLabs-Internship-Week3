 Week 3 - CRUD Application (Decode Labs Internship)
 
 📌 Project Title
CRUD Application using Database

🧠 Description
This project demonstrates CRUD operations (Create, Read, Update, Delete) using a backend server and database integration. It allows users to manage data efficiently.

⚙️ Features
- Create new records
- View all records
- Update existing records
- Delete records

🛠️ Tech Stack
- Node.js 
- Express 
- MongoDB 

🚀 API Endpoints
- POST /create
- GET /read
- PUT /update/:id
- DELETE /delete/:id
